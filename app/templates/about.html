Password Strength Checker makes a small but important part of digital security easier to understand. Built by AliAdilQ, with privacy at its core.

Your password stays yours.

Passwords entered into the checker are never stored. Live checking and generation happen entirely in your browser. The site doesn't send checker inputs to the server, write them to localStorage, or include them in analytics.

Saving a result is optional. It sends only a score, length, and four character-type flags. We don't associate results with an account or retain IP addresses in the database.

The REST API temporarily processes inputs in server memory and returns safe metadata. Only admin account passwords are hashed and stored for authentication.

How the score works.

The score combines length, character variety, and uniqueness, then subtracts points for common words, sequences, keyboard runs, repeating blocks, and predictable dates.

Common passwords are capped at 10. Dictionary-like passwords are capped at 44, even when they include familiar substitutions. Passwords under eight characters are capped at 24.

This is a transparent heuristic, not a measure of exact entropy or cracking time. It uses a small word list and doesn't check breach databases. Long, randomly selected passphrases can be good passwords without meeting every character-type checkbox.
